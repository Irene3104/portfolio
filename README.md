## About

Single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step. Designed to be fast, lightweight, and easy to deploy anywhere.

### Features

- **Responsive layout** — optimized for desktop, tablet, and mobile (down to 400px)
- **Scroll-triggered animations** — elements reveal on scroll using `IntersectionObserver`
- **Interactive effects** — cursor glow, magnetic buttons, 3D card tilt on hover
- **Animated counters** — stats count up when scrolled into view
- **Floating navigation** — pill-style nav with active section highlighting
- **Dark theme** — purple-accented dark UI with gradient highlights and noise texture

### Sections

| Section | Description |
|---------|-------------|
| Hero | Profile card, bio, stats, and CTA buttons |
| About | Core strengths and what I bring to the table |
| Experience | Career timeline with roles, descriptions, and tech stacks |
| Skills | Categorized technical skills with marquee animation |
| Projects | Featured project cards — SAIXAN, Bee-Time, Medical Imaging SDK |
| Education | Academic background (UTS, Jeonbuk National University) |
| Recommendations | Testimonials from colleagues and clients |
| Contact | Email, GitHub, LinkedIn links |

## Tech Stack

- **HTML5** / **CSS3** — custom properties, grid, flexbox, media queries
- **Vanilla JavaScript** — IntersectionObserver, requestAnimationFrame, event delegation
- **Google Fonts** — Space Grotesk, Inter

## Getting Started

No dependencies, no build tools required. Just open the file in a browser.

```bash
# Clone the repo
git clone https://github.com/Irene3104/portfolio.git

# Open in browser
open portfolio.html
```

## Deployment

This is a static single-file site. Deploy to any static hosting:

- **GitHub Pages** — push to `main` and enable Pages in repo settings
- **Vercel / Netlify** — connect the repo for automatic deploys
- **Any web server** — just serve the HTML file
